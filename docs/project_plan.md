# 项目方案说明

## 项目目标

打造一个面向企业知识管理场景的智能问答系统，重点展示 RAG、向量检索、Agent 推理与答案引用能力，适合求职面试和简历展示。

## 核心业务场景

- 员工向系统提问企业制度、流程和政策问题
- 系统从企业文档中检索相关信息
- 生成带引用来源的答案
- 通过 Agent 风格的计划，展示是否需要检索、多步推理和工具调用

## 系统架构设计

前端：Streamlit
后端：FastAPI
检索与 embedding：本地向量检索 + 文本分块
LLM：可扩展接入 OpenAI / Azure OpenAI / Ollama

## 模块划分

- 文档上传模块
- 文档预处理与分块模块
- embedding 与检索模块
- LLM 生成与回答模块
- Agent 路由与推理模块
- 前端展示模块

## MVP 功能列表

- 上传 PDF / TXT 文档
- 文档分块与构建索引
- 问答检索与生成回答
- 展示引用来源
- 展示 Agent 计划

## 推荐技术栈

- 后端：Python + FastAPI
- 前端：Streamlit
- 向量检索：本地向量实现（MVP）
- 文档解析：pypdf
- LLM：可替换 OpenAI / Ollama

## 面试亮点

- 清晰解释 RAG 的完整链路
- 展示 Agent 决策的可解释性
- 能把答案与文档来源对应起来
- 控制在 MVP 范围内，适合展示技术深度而非系统复杂度
