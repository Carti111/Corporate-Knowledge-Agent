# 面试介绍话术

你可以这样介绍这个项目：

“我做了一个面向企业知识管理场景的智能问答助手，目标不是做一个过于复杂的大型系统，而是用一个 MVP 展示我对 RAG、向量检索、Agent 路由以及 LLM 应用的理解。项目中，我实现了文档上传、文档分块、embedding 检索、答案生成和引用来源展示，并用一个轻量的 Agent 层来判断是否需要检索、是否需要多步推理以及是否需要调用工具。这让项目既有技术深度，又能被面试官很容易理解。”

## 适合强调的能力点

- 能把 LLM 应用从简单 Prompt 走向有检索支撑的 RAG 流程
- 能解释向量检索与文档切块对结果质量的影响
- 能把答案可追溯性作为工程设计重点，而不是只追求“回答看起来很流畅”
- 能把 Agent 的“判断与路由”用一个清晰的 MVP 展示出来
